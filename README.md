# Auratwin-ai
AuraTwin AI is a hardware-free, AI-powered energy management platform for commercial buildings. It uses existing Wi-Fi infrastructure to estimate occupant density, applies K-Means clustering and OR-Tools optimization to reduce energy costs, and sends control commands to HVAC systems through BACnet. 
To run double click on the Batch Script
Once started, open your browser and navigate to: 👉 http://localhost:8000 (or http://localhost:8000/dashboard)

Here you can:

View the 2D Thermal Floorplan: Real-time thermal heatmaps across all 10 zones.
Inspect Live Metrics: Building kW demand, baseline, savings, and dynamic Time-of-Use tariffs.
Simulate & Control HVAC: Click zones to adjust setpoints or click "Auto-Apply AI Setpoints" to run OR-Tools optimization.
Chat with AI Facility Manager: Ask questions like "Which zone is wasting electricity?" or "How much energy did we save today?".
